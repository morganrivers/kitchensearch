# Diagrams

**[Open the interactive program-flow diagram](https://viewer.diagrams.net/?lightbox=1&nav=1&chrome=0#Uhttps%3A%2F%2Fraw.githubusercontent.com%2Fmorganrivers%2Fkitchensearch%2Fmain%2Fdocs%2Fgraphviz%2Fkitchensearch_flow_diagram.drawio)**
(read-only draw.io viewer, no account, pan/zoom)

The viewer fetches the committed `graphviz/kitchensearch_flow_diagram.drawio`.
Regenerate it from the JSON source with:

```
cd graphviz
python build_kitchensearch_drawio.py     # rebuild the .drawio
python drawio_to_png.py kitchensearch_flow_diagram.drawio --scale 2   # optional .svg + .png
```
